# Genuine Colab development pilot — 24 October 2026

**28 completed real-model benchmark cells; no invalid cells in the schema condition.**
The matched pilot observed no attack-objective actions **and no legitimate ticket
completion**. The failed baseline utility control prevents a defense-effectiveness
conclusion. This is an exploratory capability/measurement pilot, not a confirmatory
study or an answer to transformation/deletion research questions.

## Original evidence

- `schema-compatibility.zip.xz`: the complete four-cell run. Unchanged original ZIP
  bytes are losslessly compressed with XZ, including journals and SQLite databases.
- `schema-matched.zip.xz`: all 24 matched cells, similarly preserved.
- `native-diagnostics.zip`: original installer logs, bootstrap source, two malformed
  native-output probes and one successful schema probe. These are **not benchmark
  trials**. Other CLI smoke checks lack complete raw journals and are excluded from
  the 28-trial count and the three fully journaled diagnostic probes.
- `manifest.json`: run identities, source revision, original/transport checksums,
  model digest, runtime and verified counts.
- `independent-analysis.json`: derived analysis, regenerated by `analyze.py`.
- `pilot-outcomes.svg` / `.png`: empirical figure generated by `plot.py`.

Both original ZIP hashes matched the values printed in Colab before local analysis.
The in-app browser download handoff stalled, so archives were exported as explicit
base64 text in notebook output, decoded locally, and checksum checked. XZ is a
lossless transport representation; it does not reserialize any original run file.
Checksums establish consistency with the supplied originals, not independent
attestation of the inference server.

## Recalculate without a model

From the repository root:

```bash
uv run python experiments/2026-10-24-colab/analyze.py
```

The script imports only the standard library. It verifies result hashes,
request/config identity and sampling settings; matches raw response text/tool
arguments to stored calls; reconstructs attacker retrieval from true lineage;
and checks objective/utility actions against readonly SQLite sandbox effects.
It recomputes per-condition counts and descriptive Wilson intervals. It does not
independently attest the server, validate semantic judgment, or provide human
inter-rater reliability.

To inspect original files without changing them:

```bash
python -c "import lzma,pathlib; p=pathlib.Path('experiments/2026-10-24-colab/schema-matched.zip.xz'); pathlib.Path('/tmp/memoryfence-matched-original.zip').write_bytes(lzma.decompress(p.read_bytes()))"
```

The resulting ZIP hash must equal `original_zip_sha256` in manifest.json. Extract
to a fresh directory; `memoryfence experiment audit` is an additional internal
consistency check and performs no inference. Never resume these originals under
another code revision or overwrite them to make a result look cleaner.

To regenerate the figure, using an isolated optional plotting environment:

```bash
uv run --no-project --with matplotlib==3.10.7 --python 3.12 experiments/2026-10-24-colab/plot.py
```
