## What the pilot diagnoses and what it cannot

All eight matched utility cells selected `respond`; no legitimate proposal reached
the gateway. Thus the primary failure precedes tool authorization and exact-action
execution scoring. Wrong expected arguments cannot explain the complete absence
of proposals. Raw task echoes suggest an instruction or interface problem, but do
not distinguish model capability, task ordering, native-tool/schema interactions
or resource limits. The lexical semantic judge is not a valid capability screen.

A direct inspection of the original raw responses for utility ordinals 17–24 found
522–551 prompt tokens, 28 generated tokens each, and `done_reason=stop` in all eight.
Those records do not show an exhausted 2048-token context or 256-token output cap.
Resource ablations still test whether larger limits alter behavior; they must not
be described as fixing observed truncation. Native-tool and schema interaction
remains a separate plausible interface explanation.

The pilot establishes neither defense efficacy nor general model incapacity.
It did not run transformations or deletion. It cannot answer the original research
questions on instruction persistence through summaries, consolidation, source
deletion, lineage incompleteness or broader defense/utility tradeoffs.

## Necessary additional evidence

The [prospective protocol](COMPLETION_PROTOCOL.md) freezes a high benign-competence
gate, two approved quantized model artifacts, separate message-order and example
conditions, and resource/native-tool diagnostics. An exact response control tests
whether relevant memory can support a trivial response independently of action
emission. Exact action success requires a real sandbox effect, not a text promise.
No threshold is selected using attack outcomes. Invalid calls remain visible.

Only a qualifying condition may enter the bounded clean/attack lifecycle matrix.
That matrix keeps the legitimate task constant across attack and clean twins,
uses actual local-model summaries and consolidation, and compares retained derived
memories under source deletion and cascade. If the gate fails, the absence is an
empirical result and the controlled study is not represented as executed.
