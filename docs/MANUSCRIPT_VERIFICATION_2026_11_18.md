## Proposed extensions — not executed

A subsequent study could use fresh multi-source model-written summaries and tasks
whose correct answer genuinely depends on surviving memory. It should freeze new
families and attack objectives before evaluation, qualify benign task capability,
and separate semantic judgments from exact action scoring. Multiple model artifacts
and correlated/wrong-edge treatments would address current external-validity gaps.
These are new experiments requiring their own protocol, resource approval and
accession; none is incorporated into this manuscript's original denominators.
