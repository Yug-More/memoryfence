# Limitations and remaining research

7 November 2026. Passing tests establishes checked software properties, not broad
scientific efficacy. The project is an independent research framework with a
bounded empirical study and a manuscript in preparation; no peer review or
publication is claimed. Individual contribution and study supervision require the
author's confirmation; Git authorship alone cannot establish sole ownership.

## Evidence boundaries

- Original Study: one small quantized model, three attack-chain seeds, synthetic
  tools, one objective. Eighteen attack episodes share generated memories and are
  not 18 independent source draws. Behavior used complete provenance only.
  Zero exact objective effects is neither a general protection guarantee nor a
  failed attack's explanation. Free-text echoes and a bad clean TT3 remain.
- Expanded Study: 80 deterministic configurations, 16 fixed graph families,
  seven strategies. The 560 runs are paired software executions, not model calls
  or 560 independent attacks. Four held-out graph families share the protocol,
  fixed canary and projection backend. The same investigator authored the complete
  benchmark; this is not an externally sealed or independently sampled blind test. No population confidence interval or
  significance test is justified by pretending they are random independent draws.
- Fact projection does not test semantic copying, paraphrasing, faithful summaries,
  natural-language ambiguity or generalization across models. TT labels describe
  service operations; their fixture transformation semantics are identical union.
- Five source kinds are synthetic renderings with cyclic assignment to family;
  source type is confounded with graph/content. They are not production connectors
  or independent evidence of source-type robustness. No embedding behavior is tested.
- Primary memories are deliberately excluded from expanded answer context for
  every strategy. Utility is retention/lookup of unrelated facts in derived memory,
  not LLM task success. A primary-inclusive application can have different tradeoffs.
  Empty eligible denominators are null, not failures or successes.

## Defense boundaries

Containment depends on honest operational flags and known source lifecycle. Silent
missing branches with surviving clean roots remain dangerous; incorrect edges,
forged metadata and compromised provenance writers are untested. Exact-canary
keyword filtering is strong on this fixed payload; no paraphrase resistance or
claim of outperforming that baseline generally is supported. Complete-lineage DS4
may equal the new composition; safe recomputation is an existing capability,
not a new algorithm invented by this enhancement.

Conservative quarantine can remove legitimate mixed facts. Re-derivation can reduce
that loss but cannot reconstruct facts absent from surviving inputs or guarantee
LLM faithfulness. Guard checks and actions are sequential, not a transactionally
atomic concurrent authorization protocol. SQL read isolation/import contracts do
not defend against malicious trusted Python code opening the evaluator file.

No weight unlearning, forensic deletion, real external action, authentication server,
large-model deployment or real user attack is established. Research archives retain
source-derived content intentionally. The model adapter has no paid remote fallback.

## Incomplete acceptance items and next study

The 150–300 planning target is not met; structural quality takes precedence over
padding. Incorrect/conflicting provenance, partial-source redaction, long wall-clock
delay, cross-session LLM behavior, multiple query distributions, semantic judgments,
stochastic trials and behavioral attack/utility metrics remain incomplete. The
expanded CLI is a finite all/split runner, not an arbitrary condition/repeat/model
selector or resumable matrix; older model tooling provides separate configurations.
Raw timings are one machine and order/cache-sensitive; no provenance-free matched
storage baseline or production overhead percentage is available.

Highest-value next steps: preregister a new version with stronger structural and
semantic family diversity; secure an explicitly free runtime; qualify the chosen
model's legitimate tasks before attacks; compare guarded and unguarded recomputation
under missing/incorrect provenance; validate behavioral objectives and benign
utility with human adjudication; budget independent scenario clusters before
choosing uncertainty methods. Never adapt this held-out v1 result into a purported
fresh confirmatory evaluation. Preserve failures and new accessions separately.

## Finalization clarification — 8 November 2026

A bounded model follow-up harness now exists, but its actual loopback preflight is
blocked with zero chat requests. Its future probes reuse deterministic context
and assess a literal ticket task through local sandbox actions; they do not measure
fresh semantic memory generation or general memory-dependent utility. A valid
source accession and successful empty/clean-context gate are prerequisites. Invalid
source observations, malformed replies and interrupted runs must remain explicit;
there is no full-run resume or independent verifier for future model probe results
yet. No new behavioral finding follows from its transport-fixture tests.
